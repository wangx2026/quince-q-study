# AI协作中的认知退化风险研究 Q排序

本仓库使用 [Quince](https://github.com/shawnbanasick/quince) 的静态模板，配置了50条原编号陈述和 -5 至 +5 的强制分布。

## 结果收集
本研究使用匿名本地模式。每位参与者完成后必须在控制面板下载结果文件，并自行交回研究者。浏览器内保存不等于提交，研究者不会自动收到数据。

## 来源与许可
Quince 原项目由 Shawn Banasick 等开发，按 GNU GPL v3 发布。本仓库保留原项目许可，修改了研究配置、陈述和页面入口。上游源代码见 https://github.com/shawnbanasick/quince 。
